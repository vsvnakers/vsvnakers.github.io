问题的初衷（Why - 为什么要做这个研究） ​

【问题的初衷】大型语言模型（Large Language Model, LLM）的推理效率是当前部署中的核心瓶颈。传统的全注意力（Full Attention）机制虽然能捕获长距离依赖，但其计算复杂度随序列长度呈二次方增长，导致长上下文推理成本极高。为缓解这一问题，混合注意力架构（Hybrid Attention Architecture）应运而生，它通过将全注意力层与稀疏注意力层（如滑动窗口注意力（Sliding Window Attention）、全局注意力（Global Attention）等）按层混合排列，在保持模型质量的同时显著提升推理效率。然而，如何为每一层分配最优的注意力算子（Attention Operator）是一个组合优化问题，现有方法要么依赖人工经验规则（如固定模式），要么使用基于代理信号（Proxy-based Selector）的搜索，但这些方法往往不够高效或无法找到全局最优解。例如，Jet-Nemotron 等近期工作虽然展示了自动化搜索的潜力，但其搜索阶段（PostNAS）需要消耗高达 2000 亿（200B）个 token，计算成本极其高昂，难以作为常规设计流程。因此，亟需一种快速、高效的自动化方法来搜索混合注意力架构，使得在单 GPU 上几分钟内即可完成搜索，从而推动混合注意力架构的实用化。

问题的解决（What - 提出了什么方案） ​

【问题的解决】DASH 提出了一种快速可微分搜索框架（Fast Differentiable Search Framework），用于混合注意力架构设计。其核心思路是将离散的逐层注意力算子分配问题松弛为连续的架构 logits（Architecture Logits），从而允许通过梯度下降进行端到端优化。具体而言，DASH 首先为每一层准备一组可复用的、与教师模型（Teacher Model）对齐的线性候选算子（Linear Candidates），这些算子通过预训练或知识蒸馏获得，确保搜索时模型权重冻结（Frozen Weights），仅优化架构参数。搜索过程中，DASH 使用可微分的架构搜索（Differentiable Architecture Search, DAS）方法，通过反向传播更新架构 logits，从而在极少的 token（12.3M）和极短的时间（约 20 分钟）内找到最优的混合注意力配置。与现有方法（如基于代理信号的 Selector 方法）的本质区别在于，DASH 直接以端到端的方式优化架构，避免了代理信号与真实性能之间的偏差，同时通过权重冻结和候选算子复用大幅降低了搜索成本。

技术方法详解（How - 怎么实现的） ​

【技术方法详解】

  • 连续松弛化（Continuous Relaxation）：将离散的层注意力算子选择问题转化为连续优化问题。对于每一层，定义一组候选算子（如全注意力、滑动窗口注意力、全局注意力等），每个算子对应一个可学习的架构权重（Architecture Weight）α。通过 softmax 函数将 α 归一化为概率分布，最终输出为各算子的加权和，从而实现可微分搜索。
  • 可复用教师对齐线性候选（Reusable Teacher-Aligned Linear Candidates）：为减少搜索时的计算开销，DASH 预先为每个候选算子生成与教师模型（如 Qwen2.5-3B-Instruct）对齐的线性投影（Linear Projections）。这些候选算子通过知识蒸馏（Knowledge Distillation）或直接复制教师权重获得，搜索时模型权重完全冻结，仅更新架构 logits。
  • 架构-权重解耦搜索（Architecture-Weight Decoupled Search）：与传统可微分搜索（如 DARTS）不同，DASH 在搜索过程中不更新模型权重（如注意力头参数），仅优化架构参数。这避免了权重与架构的耦合，大幅降低了搜索空间和计算量。
  • 单 GPU 高效实现：通过精心设计的算子融合（Operator Fusion）和内存优化，DASH 在单个 RTX Pro 6000 GPU 上即可完成搜索，仅需 12.3M token（约 20 分钟），相比 Jet-Nemotron 的 200B token 降低了 99.994% 的计算量。
  • 搜索后微调（Post-Search Fine-Tuning）：搜索完成后，根据架构 logits 选择最优算子组合，然后对模型进行少量微调以恢复性能。微调阶段仅需少量 token（如 1B），远低于从头训练的成本。

核心公式与算法 ​

【核心公式】

  1. 连续松弛化公式： $$ \bar{o}^{(l)}(x) = \sum_{i=1}^{N} \frac{\exp(\alpha_i^{(l)})}{\sum_{j=1}^{N} \exp(\alpha_j^{(l)})} \cdot o_i^{(l)}(x) $$ 其中，$\bar{o}^{(l)}$ 是第 $l$ 层的混合输出，$\alpha_i^{(l)}$ 是第 $i$ 个候选算子的架构 logit，$o_i^{(l)}$ 是第 $i$ 个候选算子的输出。该公式将离散选择松弛为连续加权和。
  2. 搜索损失函数： $$ \mathcal{L}{search} = \mathcal{L}(y, \hat{y}) + \lambda \sum_{l} |\alpha^{(l)}|2 $$ 其中，$\mathcal{L}$ 是交叉熵损失，$\lambda$ 是正则化系数，用于鼓励稀疏的架构选择。
  3. 架构选择公式： $$ o^{(l)*} = \arg\max_{i} \alpha_i^{(l)} $$ 搜索完成后，选择每个层中 logit 最大的算子作为最终配置。

具体技术细节示例（How in Action - 算法如何执行） ​

【具体技术细节示例】假设我们使用 DASH 为一个小型语言模型搜索混合注意力架构，模型有 3 层（L=3），每层候选算子池包含 3 个选项：全注意力（Full Attention, FA）、滑动窗口注意力（Sliding Window Attention, SWA，窗口大小 w=4）、全局注意力（Global Attention, GA）。输入序列长度为 8（N=8），token 嵌入维度为 16（d=16）。搜索过程如下：

步骤 1：初始化架构 logits 为每层定义可学习架构权重 α，初始化为零向量：α_1 = [0, 0, 0], α_2 = [0, 0, 0], α_3 = [0, 0, 0]。通过 softmax 归一化得到初始概率分布：p_1 = [1/3, 1/3, 1/3]，类似地 p_2 和 p_3。

步骤 2：准备教师对齐线性候选 从教师模型（如 Qwen2.5-3B）中提取每个候选算子的线性投影权重。例如，FA 的查询（Query）、键（Key）、值（Value）投影矩阵为 W_Q_FA, W_K_FA, W_V_FA，尺寸均为 16×16。SWA 和 GA 类似，但 SWA 的注意力掩码（Attention Mask）限制为局部窗口。这些权重在搜索期间冻结。

步骤 3：前向传播计算输出 对于第 1 层，输入 X 为 8×16 矩阵。计算每个候选算子的输出：

  • FA 输出：O_FA = softmax(X W_Q_FA (X W_K_FA)^T / sqrt(16)) X W_V_FA，尺寸 8×16。
  • SWA 输出：O_SWA = softmax(掩码后的注意力分数) X W_V_SWA，掩码仅允许每个 token 关注前后 4 个 token。
  • GA 输出：O_GA = softmax(全局掩码) X W_V_GA，全局掩码允许所有 token 关注前 2 个特殊 token（如 [CLS]）。 然后，混合输出 O_1 = p_1[0] * O_FA + p_1[1] * O_SWA + p_1[2] * O_GA。类似地计算第 2 层和第 3 层，最终输出通过线性层得到预测 logits，尺寸为 8×V（V 为词表大小，假设 V=1000）。

步骤 4：计算损失并反向传播 使用交叉熵损失（Cross-Entropy Loss）比较预测 logits 与真实 token 标签。例如，输入序列为 [token_1, token_2, ..., token_8]，目标为 [token_2, token_3, ..., token_9]。损失 L = -sum(log(softmax(logits)[target]))。反向传播时，仅更新 α 参数，模型权重不变。假设梯度 ∂L/∂α_1 = [0.2, -0.1, -0.1]，则更新 α_1 = α_1 - lr * gradient，lr=0.01，得 α_1 = [-0.002, 0.001, 0.001]。重新 softmax 后 p_1 ≈ [0.332, 0.334, 0.334]。

步骤 5：迭代优化 重复步骤 3-4 共 100 步，使用 12.3M token 的子集。最终 α 收敛，例如 α_1 = [1.5, 0.2, -0.7]，softmax 后 p_1 = [0.78, 0.18, 0.04]，选择 FA 作为第 1 层算子。类似地，第 2 层选择 SWA，第 3 层选择 GA。

输出：最终混合注意力架构为 [FA, SWA, GA]，搜索耗时约 20 分钟。之后用 1B token 微调模型，在长上下文任务上推理速度提升 2 倍，困惑度仅增加 0.3%。
