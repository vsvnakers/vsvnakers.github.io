问题的初衷（Why - 为什么要做这个研究） ​

【问题的初衷】随着视频生成（Video Generation）与世界模型（World Model）的快速发展，自回归（Autoregressive）推理过程中的键值缓存（KV Cache）已成为部署阶段的主要显存瓶颈。视频序列的时空令牌（Temporal-Spatial Tokens）数量远超文本，导致 KV Cache 显存占用随帧数线性甚至超线性增长，严重限制了长视频生成与实时世界模型的可扩展性。现有工作尝试用 2-bit 极低位量化（如 KIVI、KVQuant 等）压缩 KV Cache，并在 VBench 等视频基准上报告了近乎无损的指标表现。然而，论文作者发现这些方法虽然能维持基准分数，却在实际视觉呈现上引发严重的时序闪烁（Temporal Flickering）与画面退化，即指标与主观视觉质量之间存在显著鸿沟。更深入的探究揭示了一个反直觉现象：Key 的量化重建误差小于 Value，但其导致的输出退化却远大于 Value。作者将这一矛盾追溯到注意力机制（Attention Mechanism）本身——Key 的微小扰动会改变注意力逻辑值（Attention Logits，即 QKop），进而改变 Query 所选择的时空令牌集合，破坏帧间一致性。这一发现表明，仅以重建误差为优化目标的传统量化范式并不适用于视频/世界模型场景，必须显式保护注意力逻辑值与令牌选择行为，才能从根本上缓解视觉退化。

问题的解决（What - 提出了什么方案） ​

【问题的解决】针对上述问题，论文提出了 QuantWM，一个免训练（Training-Free）且严格因果（Strictly Causal）的 2-bit KV Cache 量化框架。其核心思路是：不再单纯最小化 Key/Value 的重建误差，而是显式地保持注意力逻辑值 QKop 与时空令牌选择的一致性。QuantWM 由两个互补技术构成。第一，量化敏感度感知聚类（Quantization-Sensitivity-Aware Clustering, QSAC）：它联合考虑历史 Query 敏感度与残差范围，为 Key 选择对 INT2 友好的聚类中心（Centroids），从而在那些对注意力更关键的通道上降低量化误差。第二，主子空间注意力补偿（Principal-Subspace Attention Compensation, PSAC）：在 QSAC 之后，利用低秩投影（Low-Rank Projection）沿主导 Query 子空间恢复剩余的 Key 误差，对注意力逻辑值进行直接且高效的校正。与现有方法相比，QuantWM 的本质区别在于：它把量化目标从“数值重建精度”转向“注意力行为保真”，并且完全免训练、严格因果，可直接插入现有自回归视频生成与世界模型推理管线，在实现最高 6.20 倍 KV Cache 显存压缩的同时，显著提升视觉质量与时序一致性。

技术方法详解（How - 怎么实现的） ​

【技术方法详解】

  • 问题诊断与动机建模：论文首先通过实验量化 Key 与 Value 的量化重建误差及其对输出的影响，发现 Key 误差虽小却导致更大的输出退化。作者将原因归结为注意力逻辑值 QK⊤ 对 Key 扰动的敏感性，以及由此引发的时空令牌选择漂移。
  • 量化敏感度感知聚类（QSAC）：QSAC 在聚类选择聚类中心时，不仅考虑 Key 残差的数值范围，还引入历史 Query 的敏感度权重。具体而言，对每个通道计算其历史 Query 激活强度，作为该通道对注意力重要性的度量，并据此加权聚类损失，使 INT2 聚类中心优先拟合对注意力关键的通道。
  • 主子空间注意力补偿（PSAC）：QSAC 之后仍存在残余 Key 误差。PSAC 通过低秩投影将残余误差投影到主导 Query 子空间（即 Query 协方差矩阵的主特征向量张成空间），仅在该子空间内进行补偿，从而以极低计算开销直接稳定注意力逻辑值。
  • 严格因果与免训练设计：QuantWM 的所有统计量（历史 Query 敏感度、残差范围、主子空间）均仅依赖当前及历史令牌，满足自回归生成的因果约束；同时不引入任何梯度更新或微调，可直接部署于推理阶段。
  • 与现有量化框架的兼容性：QuantWM 可作为插件替换现有 2-bit KV Cache 量化中的 Key 量化模块，保持 Value 量化策略不变，从而在 KIVI、KVQuant 等框架上即插即用。
  • 复杂度与开销控制：QSAC 的聚类与 PSAC 的低秩投影均按通道或按子空间进行，额外开销主要来自少量矩阵乘法与投影运算，相对于注意力计算本身可忽略，论文报告其额外开销有限。

核心公式与算法 ​

【核心公式】

Attention(Q,K,V)=softmax(QK⊤d)V

该式为标准缩放点积注意力，论文指出 Key 的微小扰动会改变 QK⊤，从而改变 softmax 后的令牌选择权重，是视觉退化的根源。

LQSAC=∑cwc⋅∥Kc−Cc∥2,wc=f(历史 Query 敏感度c,残差范围c)

该式表示 QSAC 的加权聚类目标，wc 为通道 c 的敏感度权重，Cc 为 INT2 聚类中心，使关键通道获得更小量化误差。

ΔKPSAC=PQPQ⊤(K−K^)

该式表示 PSAC 的补偿项，PQ 为主导 Query 子空间的正交基，(K−K^) 为残余 Key 误差，通过投影到主子空间直接校正注意力逻辑值。

具体技术细节示例（How in Action - 算法如何执行） ​

【具体技术细节示例】假设当前解码步，模型有 4 个通道的 Key 缓存，历史 Query 敏感度向量为 w=[0.9,0.1,0.7,0.3]，当前 Key 向量为 K=[1.2,−0.5,0.8,0.4]，残差范围为 [0.3,0.1,0.25,0.15]。第一步，QSAC 计算综合权重：通道 1 敏感度 0.9、残差 0.3，权重最高；通道 2 敏感度 0.1、残差 0.1，权重最低。据此选择 INT2 聚类中心，例如 C=[1.0,−0.5,0.75,0.5]，使通道 1 与通道 3 的量化误差更小。第二步，Key 量化反量化后得到 K^=[1.0,−0.5,0.75,0.5]，残余误差 ΔK=K−K^=[0.2,0.0,0.05,−0.1]。第三步，PSAC 使用主导 Query 子空间基 PQ（假设为二维子空间，投影矩阵近似为单位阵在前两维），计算补偿 ΔKPSAC=PQPQ⊤ΔK≈[0.2,0.0,0.0,0.0]，将误差集中补偿到对注意力最关键的通道 1。第四步，更新后的 Key 为 K^+ΔKPSAC=[1.2,−0.5,0.75,0.5]，其与原始 Key 在关键通道上完全一致，注意力逻辑值 QK⊤ 的漂移被显著抑制。最终，注意力输出保持稳定，生成的下一帧在时序上与历史帧一致，避免了闪烁。该示例展示了 QSAC 如何优先保护关键通道，以及 PSAC 如何用低秩投影直接校正残余误差，二者协同实现注意力逻辑值保真。
