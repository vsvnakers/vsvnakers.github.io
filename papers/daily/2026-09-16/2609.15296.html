问题的初衷（Why - 为什么要做这个研究） ​

【问题的初衷】通用多模态嵌入（Universal Multimodal Embedding, UME）旨在学习跨模态的统一表示，使单一模型能够支持多样化的检索任务。近年来，研究者引入思维链（Chain-of-Thought, CoT）推理机制，让模型在生成嵌入向量之前先对多模态输入进行推理，从而更好地理解复杂检索任务，并通过基于检索奖励的 GRPO（Group Relative Policy Optimization）进一步优化推理过程。然而，这类方法在语料库规模部署时面临两个关键瓶颈。第一，GRPO 在信用分配（Credit Assignment）上过于粗糙：它为所有 CoT token 分配相同的优势值（Advantage），无法识别哪些 token 真正基于输入证据、能够区分正样本与负样本，导致监督信号噪声大、训练效率低。第二，推理延迟问题严重：模型必须在每次生成嵌入之前完成整条 CoT，即使部分推理轨迹已经提供了足够的检索证据，仍然要生成完整链条，造成大量冗余计算。这两个问题共同阻碍了推理增强型 UME 在大规模检索场景中的实际落地，因此亟需一种既能精细分配推理信用、又能自适应控制推理长度的新框架。

问题的解决（What - 提出了什么方案） ​

【问题的解决】论文提出 Reason What Matters（ReWAM），一个以检索反馈为核心的推理框架，用检索信号同时指导信用分配与推理计算。其核心思路包含两个互补组件。第一，检索感知自蒸馏（Retrieval-aware Self-Distillation, RASD）：它从输入支持的证据中构造特权指导（Privileged Guidance），这些证据能够区分正样本与检索到的难负样本；随后一个在策略自教师（On-policy Self-teacher）利用该指导，将轨迹级反馈细化为 token 级监督，使真正与检索相关的推理步骤获得更高权重，而无关或冗余的推理 token 被抑制。第二，检索自适应推理（Retrieval-adaptive Inference, RAI）：它引入一个检索置信度头（Retrieval Confidence Head），用于估计部分 CoT 的剩余检索效用；当置信度足够高时提前终止推理，避免无效轨迹；当继续推理仍有价值时，则通过投机解码（Speculative Decoding）加速后续生成。与现有方法相比，ReWAM 的本质区别在于：不再对所有 CoT token 一视同仁，也不再固定生成完整 CoT，而是让检索反馈动态决定“哪些推理重要”以及“推理到何时为止”，从而在检索质量与推理效率之间取得平衡。

技术方法详解（How - 怎么实现的） ​

【技术方法详解】

  • 检索感知自蒸馏（RASD）：从输入中抽取能够区分正样本与难负样本的证据片段，构造特权指导信号。该信号不依赖人工标注，而是由检索反馈自动生成，用于判断哪些推理步骤真正具有判别力。
  • 在策略自教师机制：使用一个与策略模型同源的自教师模型，在策略分布上对轨迹进行重新评估，将原本粗粒度的轨迹级奖励分解为 token 级监督信号，实现精细信用分配。
  • 检索置信度头（Retrieval Confidence Head）：在推理过程中实时估计当前部分 CoT 的剩余检索效用，输出一个置信度分数，用于判断是否继续推理。
  • 检索自适应推理（RAI）：基于置信度头的结果，动态决定提前终止或继续推理；对有价值的续写轨迹使用投机解码加速，降低自回归生成开销。
  • GRPO 与检索奖励结合：在训练阶段，将检索指标（如正样本排名、负样本区分度）作为奖励信号，结合 RASD 的 token 级监督，联合优化推理策略与嵌入生成。
  • 多模态统一嵌入生成：最终嵌入由推理后的表示生成，支持文本、图像及其组合的跨模态检索任务。

优势与不足 ​

【优势与不足】

  • 优势：
    1. 提出 token 级信用分配机制，利用检索反馈区分正负样本证据，显著提升推理监督的精度与训练效率。
    2. 引入检索置信度头实现自适应推理终止，结合投机解码，在保持检索质量的同时大幅提升推理吞吐量。
    3. 在多个权威多模态检索基准上达到 state-of-the-art，并验证了推理质量与效率可以兼得。
  • 不足：
    1. 检索置信度头的训练依赖检索反馈信号，在冷启动或检索器质量较差时可能估计不准，影响提前终止决策。
    2. 方法组件较多（RASD、自教师、置信度头、投机解码），系统实现与调参复杂度较高，复现和部署成本较大。
    3. 实验主要集中在检索任务，尚未验证在生成式多模态任务或其他下游任务上的泛化能力。
