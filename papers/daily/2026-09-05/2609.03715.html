问题的初衷（Why - 为什么要做这个研究） ​

【问题的初衷】近年来，视觉-语言-动作模型（Vision-Language-Action Model, VLA）在机器人操作领域取得了显著进展，尤其是在 LIBERO 基准测试上，具有数十亿参数的大型模型（如 π₀.₅）已成为主流方法。然而，这些模型的巨大规模带来了高昂的训练和推理成本，限制了其在真实机器人系统中的部署效率。一个关键问题尚未得到解答：LIBERO 基准本身到底需要多大的模型容量才能成功解决？现有研究普遍关注如何扩大模型规模以提升性能，却忽视了任务特定的容量下限（capacity floor）。这种‘越大越好’的范式不仅导致计算资源浪费，也阻碍了高效、轻量级策略的设计。因此，本文旨在通过系统性地缩小策略模型，探索 LIBERO 任务所需的最小参数规模，从而为容量感知的模型设计和知识蒸馏提供实证基础。这一研究动机源于对部署效率和模型可解释性的双重需求，尤其在资源受限的嵌入式机器人平台上，小型化策略具有重要的实际意义。

问题的解决（What - 提出了什么方案） ​

【问题的解决】本文提出了 MINERVA（MINimal Efficient Robotic Vision-Action policy），一个极简的视觉运动策略（visuomotor policy）家族，用于精确测量 LIBERO 基准的任务特定容量下限。核心思路是：通过系统性地缩减模型参数规模，同时保持高成功率，来揭示任务对容量的真实需求。MINERVA 采用紧凑的视觉编码器（如 ResNet-18）和轻量级动作解码器，结合直接 L1 回归（direct L1 regression）作为动作预测目标，而非复杂的流匹配（flow matching）方法。关键创新点包括：1）首次提供了 LIBERO 的容量下限估计，发现约 0.54M 参数即可达到 95.1% 的平均成功率；2）通过广泛的架构、训练和推理扫描，识别出动作块长度（action-chunk length）和视觉容量是影响性能的关键因素；3）证明了任务 ID 置换探针（task-ID permutation probe）揭示 LIBERO 指令条件化主要依赖记忆而非语义理解。与现有大型 VLA 模型的本质区别在于，MINERVA 强调‘最小充分性’而非‘最大扩展性’，为高效策略设计提供了新视角。

技术方法详解（How - 怎么实现的） ​

【技术方法详解】

  • 模型架构：MINERVA 采用两阶段架构，视觉编码器使用 ResNet-18（约 0.11M 参数）提取图像特征，动作解码器为多层感知机（MLP）或小型 Transformer，将视觉特征和语言嵌入映射为动作序列。总参数范围从 0.25M 到 2M，核心版本为 0.54M 参数。
  • 动作表示：策略输出离散化的动作块（action chunk），长度为 Tchunk（如 16 或 32 步），每个动作维度包括末端执行器的位置、旋转和夹爪状态。动作预测使用直接 L1 回归损失函数，公式为 L=1N∑i=1N|ai−a^i|，其中 ai 是真实动作，a^i 是预测动作。
  • 语言条件化：使用预训练的语言编码器（如 DistilBERT）将任务指令编码为固定长度的嵌入向量，然后与视觉特征拼接（concatenate）后输入解码器。任务 ID 置换实验表明，语言条件化主要作为任务选择器而非语义理解器。
  • 训练策略：使用行为克隆（Behavioral Cloning, BC）从 LIBERO 的专家演示中学习，优化器为 AdamW，学习率调度采用余弦退火（cosine annealing）。训练在单个 GPU 上完成，时间约 2-4 小时，远快于大型 VLA 模型。
  • 推理优化：在推理阶段，策略以 5-9 毫秒/块的速度在笔记本电脑 CPU 上重规划，无需 GPU。通过量化（quantization）和剪枝（pruning）进一步压缩模型，但实验显示 0.54M 参数已接近性能饱和点。
  • 容量扫描：通过改变隐藏层宽度和深度，生成不同参数量的变体（0.25M、0.54M、1M、2M），并评估其在 LIBERO 四个套件上的成功率，以绘制容量-性能曲线。

核心公式与算法 ​

【核心公式】

  1. 动作预测损失函数：$$\mathcal{L}{L1} = \frac{1}{N} \sum^{N} \left| a_i - \hat{a}_i \right|$$ 其中 ai 是第 i 个时间步的真实动作，a^i 是模型预测的动作，N 是动作块长度。该损失用于行为克隆训练，直接最小化预测误差。
  2. 动作块重规划策略：在推理时，模型预测长度为 Tchunk 的动作块，但只执行前 k 步（通常 k=1 或 k=5），然后重新观测环境并再次预测。这类似于模型预测控制（Model Predictive Control, MPC）的滚动时域优化。
  3. 容量-性能关系：通过扫描参数数量 P，观察到成功率 S 满足 S≈αlog⁡(P)+β（在 P∈[0.25M,1M] 范围内），其中 α 和 β 是拟合常数，表明性能随容量对数增长，但存在饱和点。

具体技术细节示例（How in Action - 算法如何执行） ​

【具体技术细节示例】假设我们使用 MINERVA 的 0.54M 参数版本在 LIBERO-Spatial 套件上执行任务“将碗从桌子左侧移动到右侧”。输入为 224x224x3 的 RGB 图像和文本指令。具体执行步骤如下：

  1. 输入预处理：图像被归一化到 [0,1] 范围，文本指令被 tokenize 并编码为 768 维向量（使用 DistilBERT）。
  2. 视觉特征提取：ResNet-18 将图像编码为 512 维特征向量 v，经过平均池化后得到 v∈R512。
  3. 特征拼接：将视觉特征 v 与语言嵌入 l 拼接，得到 f=[v;l]∈R1280。
  4. 动作解码：解码器是一个 2 层 MLP，隐藏层维度为 256，输出动作块 A∈RTchunk×7，其中 Tchunk=16，7 个维度包括位置 (3)、旋转 (3) 和夹爪 (1)。假设预测的第一个动作块为 A1，其中第一个时间步的动作 a1=[0.1,0.2,0.3,0.0,0.0,0.5,1.0]（位置增量、旋转增量和夹爪开合）。
  5. 执行与重规划：机器人执行 a1 的前 1 步（k=1），然后获取新图像，重复步骤 2-4。假设经过 50 步后，碗被移动到目标位置，任务成功。

实验结果（Results - 效果如何） ​

【实验结果】实验在 LIBERO 基准的四个标准套件上进行：LIBERO-Spatial、LIBERO-Object、LIBERO-Goal 和 LIBERO-100（包含 10 个任务），每个套件包含 50 个专家演示用于训练。MINERVA 的 0.54M 参数策略在 2,000 次 rollout（每个套件 500 次）中实现了 95.1% 的平均成功率，仅比 LeRobot 报告的 π₀.₅ 结果低 2.4 个百分点，但参数数量减少了 7,700 倍。性能在约 1M 参数时饱和，低于 0.25M 参数时性能急剧下降。在架构、训练和推理的广泛扫描中，只有动作块长度和视觉容量对性能的影响持续超过 ±1 个百分点的训练种子差异。流匹配（flow matching）与直接 L1 回归相比，在三个种子上没有检测到优势，而回归在 GPU 上快达 3.8 倍。任务 ID 置换探针显示，改变任务 ID 映射将成功率降至接近随机水平，表明标准 LIBERO 指令条件化主要选择记忆任务。在 LIBERO-90 的 89 个任务上，相同配方实现了 94.6% 的成功率，而 LIBERO-Plus 扰动将性能降至 46-56%，对光度变化（photometric shifts）的鲁棒性接近零。推理速度方面，0.54M 策略在笔记本电脑 CPU 上每块重规划仅需 5-9 毫秒，比 SmolVLA 快 113 倍，比 π₀.₅ 快 1,400 倍，且无需 GPU。

优势与不足 ​

【优势与不足】

  • 优势 1：首次提供了 LIBERO 基准的任务特定容量下限的实证估计，为高效策略设计提供了理论指导。
  • 优势 2：极小的模型规模（0.54M 参数）实现了接近大型 VLA 模型的性能，显著降低了计算和存储成本，支持在边缘设备上实时推理。
  • 优势 3：通过系统性的消融实验，揭示了动作块长度和视觉容量是影响性能的关键因素，为后续研究提供了可复用的设计原则。
  • 优势 4：任务 ID 置换探针提供了对 LIBERO 基准局限性的深刻洞察，有助于社区重新评估基准的有效性。
  • 不足 1：对 LIBERO-Plus 等扰动场景的鲁棒性极低，表明模型泛化能力有限，可能过度拟合训练分布。
  • 不足 2：容量扫描仅在 LIBERO 基准上进行，结论可能不适用于更复杂、更真实的任务，缺乏跨基准的验证。
  • 不足 3：语言条件化的记忆性依赖可能限制了模型在开放世界任务中的语义理解能力，需要进一步改进。
